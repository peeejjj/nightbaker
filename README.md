# The Night Bakery

A single-file, phone-first web app that turns a child's wind-down and bedtime into a bakery-building game. Rest is the ingredient: dough proves overnight, and a rested morning is a good bake.

- Open `night-bakery.html` on any phone, tablet or computer. No install, no account.
- Everything stays on the device (localStorage). Nothing is sent anywhere.
- All game numbers live in the `CONFIG` block at the top of the script so they can be tuned in session.

Built by AkindaCo as a rough draft for co-creation. No client identifiers are stored or shown.
